# Dex Fedora
**Version 2.5.9**

Dex Fedora is a modified and enhanced version of the original Dex that is PRIVATE, developed by **The Fedora Group** with a focus on improving functionality, usability, and overall performance.

Designed to provide a more refined development and inspection experience, Dex Fedora introduces upgraded tools, improved decompilation capabilities, and additional features to make working with scripts and exploring game structures more convenient.

### Features & Improvements
- **AI Beautifier** – Uses AI-assisted formatting to improve code readability and structure.
- **Local Beautifier** – Provides local code beautification without relying on external AI services.
- **Improved Decompiler** – Enhanced decompilation for better code output and readability.
- **Fallback Decompiler** – An additional decompiler option when the primary decompiler fails.
- **Updated Dump** – Updated dumping functionality for a more refined inspection experience.

### What's New in 2.5.9
Version 2.5.9 brings several improvements and additions, focusing on better code readability, more reliable decompilation, and an overall improved Dex experience.
